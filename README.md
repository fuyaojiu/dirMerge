# DirMerge

一个 Tauri 2 桌面工具，用来把两个文件夹合并到一起。

## 功能

- 选择“原始文件夹”作为合并目标。
- 选择“要合并的文件夹”作为来源。
- 可选择复制或移动来源内容。
- 可选择是否生成 `重复文件` 目录。
- 同名子文件夹会递归合并。
- 开启生成重复文件时，同名文件不会覆盖，来源文件会进入当前目标目录下的 `重复文件` 目录。
- 关闭生成重复文件时，同名文件会跳过；移动模式下，被跳过的重复文件会留在来源目录。

## 开发运行

```sh
npm install
npm run tauri dev
```

如果本机还没有 Rust 工具链，需要先安装 Rust 和 Cargo。
